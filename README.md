# About Me

Hi, I'm **Akhil Yalamanchili**, currently pursuing my **Master of Computer Applications (MCA) at M. S. Ramaiah Institute of Technology (MSRIT), Bengaluru**, after completing my BCA in Data Science from Presidency University.

I'm passionate about building practical solutions using **Artificial Intelligence, Machine Learning, Data Science, and Software Development**.

I enjoy taking ideas from concept to implementation, exploring new technologies, and learning by building real-world applications.

### What I Work On

- Artificial Intelligence & Machine Learning
-  Deep Learning & Computer Vision
-  Data Analytics & Data Visualization
-  Full-Stack Web Development
-  AI Agents & Workflow Automation
-  Experimentation, Model Evaluation & Deployment

### Core Toolkit

- **Languages:** Python, SQL, JavaScript, TypeScript, C, R
- **AI/ML:** TensorFlow, PyTorch, Scikit-learn, Keras
- **Data:** Pandas, NumPy, Matplotlib, Power BI, Excel
- **Web:** React, Next.js, HTML, CSS, Tailwind CSS
- **Backend:** FastAPI, REST APIs
- **Databases:** MySQL, MongoDB, SQLite
- **Tools:** Git, GitHub, VS Code, Jupyter Notebook, Figma

 Currently focused on improving my software engineering skills, exploring advanced AI/ML concepts, and building applications that solve practical problems.

 Always learning. Always building.
